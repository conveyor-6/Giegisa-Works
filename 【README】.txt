======【交互说明】======
***！必设置内容！***
初次使用时，请右键进入菜单，填写“核心数据接口与设置”中的各项内容。
（1）建议将默认兼容引擎改为open AI，使用硅基流动作为“接口地址”（https://api.siliconflow.cn/v1），在“模型名称”里填写“Qwen/Qwen3-VL-30B-A3B-Thinking”。注册硅基流动，生成你自己的api key并粘贴至填写区内。
（2）若在国内代理情况下使用gemini，在填写你自己的api key后，可在“强制本地代理”项填写 http://127.0.0.1:XXXX（XXXX 改成你代理软件的本地端口，即四位数字，每个梯子都会提供）；也可以留空，程序会自动走电脑系统代理。填或不填都不影响挂梯使用。
（3）若外界大模型更新，请及时更改接口地址、模型名称和api key。
（3.5）【读图模型】"核心数据与接口设置"→"OpenAI 兼容引擎设置"中有"主模型支持读图"勾选框（白名单制，不靠模型名判断）：主模型能读图就勾上，贴图直接走主模型；主模型不能读图（如 deepseek）就取消勾选，并在下方"读图模型设置"填一个能读图的模型（API Key 和接口地址留空则沿用上方主模型的）。贴图发送时程序会自动把图片临时交给读图模型识别，平时文字对话仍走主模型；读图模型留空则不启用此功能。
（4）如果giegisa说“接口异常+一大串错误提示符”，把截图扔给豆包ds等市面上的任意AI让它看看。一般问题不大，是大模型的问题，换个接口或者等一会就行了。

0.每天启动桌宠时，用户均可获得50数据碎片。
1.移动与放置：按住鼠标左键拖动 Giegisa ，即可将其移动到屏幕上的任意位置。  
2.唤出菜单：在 Giegisa 身上点击鼠标右键，或点击系统托盘图标，即可唤出主菜单栏。  
3.文字对话：回车发送，shift+回车换行。如剪贴板有图像，ctrl+v即可粘贴至文本框中。您可以通过在设置中隐藏或显示该输入面板。  
4.如您接入Gemini等可传回图片的大模型，并发送“希望gisa发来图片”的请求，Giegisa将会在新窗口中显示图片。这些图片不会占用本地内存。
5.剪贴板及媒体识别：当您剪贴板中有内容时，可以通过浮出的按钮让Giegisa对剪贴板内容做出反应。如果您通过常见应用或网页开启了音乐或视频播放，Giegisa可以识别标题并对其做出评价。两项功能均可关闭。
